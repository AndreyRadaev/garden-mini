# GARDEN Mini на GitHub Pages

Статическая страница показывает план, выручку, средний чек и конверсию бариста. Посетитель и программа загружают только зашифрованный файл с `*.github.io`; прямых запросов к Vercel у них нет. GitHub Actions раз в 15 минут получает `/api/compact` из дашборда, шифрует ответ и публикует новую версию Pages. Запуск по расписанию может задерживаться, поэтому интерфейс показывает время фактического обновления.

Для запуска создайте отдельный **публичный** репозиторий GitHub и поместите туда содержимое этой папки (не весь исходный проект). В Settings → Secrets and variables → Actions добавьте `DASHBOARD_LOGIN` и `DASHBOARD_PASSWORD` для роли с ограниченным доступом, а также отдельную длинную фразу `SNAPSHOT_PASSPHRASE` (не менее 16 символов). Не помещайте значения секретов в файлы репозитория. В Settings → Pages выберите источником GitHub Actions. Первый запуск сделайте через Actions → «Обновить показатели» → Run workflow.

Файл `/data/current.enc.json` публично скачивается, но его содержимое зашифровано AES-256-GCM. Чтобы использовать данные в сторонней программе, ей понадобится та же парольная фраза для расшифровки. Не используйте пароль от дашборда в качестве этой фразы. Отдельный пароль просмотра не хранится на странице.

Пока не создан репозиторий и не заданы секреты, сайт не опубликован. Если GitHub Actions не сможет обратиться к дашборду, обновление завершится ошибкой, а предыдущая опубликованная версия останется доступной.
