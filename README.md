# GARDEN Mini на GitHub Pages

Открытая страница показывает планы, выручку, средний чек и конверсию бариста. Посетитель и программа загружают готовый файл `/data/current.json` с `*.github.io`; прямых запросов к Vercel у них нет.

GitHub Actions получает данные из `/api/compact` основного дашборда и публикует новую версию Pages. Попытки обновления запланированы каждые пять минут, но GitHub может задерживать или пропускать запуск. На странице показано время фактического расчёта. При сбое предыдущая опубликованная версия остаётся доступной.

Для фонового получения данных секреты `DASHBOARD_LOGIN` и `DASHBOARD_PASSWORD` остаются только в настройках GitHub Actions. Они не попадают в опубликованный JSON. Пароль для просмотра больше не нужен. Данные в `/data/current.json` публичны — не добавляйте в ответ `/api/compact` сведения, которые нельзя публиковать.
